# StudyLock Android

A student-focused Android app for distraction-free study sessions.

## Initial stack
- Kotlin
- Jetpack Compose
- Material 3
- Android Gradle Plugin
- Local-first architecture

## Planned features
- Study Mode
- Study timer
- App selection and restrictions
- Allowed study apps
- Focus statistics
- Settings
- Xiaomi/HyperOS compatibility considerations
